# 날씨

도시 이름을 입력하면 현재 날씨와 7일 예보를 보여주는 웹 앱입니다.
HTML 파일 하나로 되어 있으며, 설치나 회원가입 없이 브라우저에서 바로 사용할 수 있습니다.

**바로 사용하기: https://amoslee6204.github.io/exe/weather.html**

## 주요 기능

- **도시 검색**: 서울, 부산, 제주 같은 국내 도시와 Tokyo, Paris 같은 해외 도시를 검색할 수 있습니다.
- **내 위치**: 버튼을 누르고 위치 권한을 허용하면 현재 위치의 날씨를 보여줍니다.
- **현재 날씨**: 기온, 체감온도, 날씨 상태, 습도, 풍속(m/s), 강수량(mm)
- **7일 예보**: 날짜별 날씨, 최고·최저 기온, 강수 확률
- **코스피 지수**: 전 거래일 종가, 현재(최근 거래일) 지수, 그 차이와 등락률을 보여줍니다. 상승은 빨강(▲), 하락은 파랑(▼)으로 표시하며, 실시간이 아니고 최대 20~30분 늦을 수 있습니다.
- **화면 모드**: 기기 설정에 따라 라이트·다크 모드가 자동으로 바뀌고, PC와 휴대폰 화면에 맞춰 표시됩니다.

처음 열면 서울 날씨가 기본으로 표시됩니다.

## 사용 방법

1. 위 링크를 엽니다.
2. 입력창에 도시 이름을 넣고 **검색**을 누릅니다.
3. 현재 위치의 날씨를 보려면 **내 위치**를 누르고 브라우저의 위치 권한 요청을 허용합니다.

## 데이터 출처

날씨와 지명 검색 데이터는 [Open-Meteo](https://open-meteo.com/)의 무료 공개 API를 사용합니다.
API 키가 필요 없으며, 앱은 별도 서버 없이 브라우저에서 Open-Meteo로 직접 데이터를 받아옵니다.

코스피 지수는 Yahoo Finance(`^KS11`) 데이터입니다. 브라우저에서 직접 받을 수 없어서
GitHub Actions(`.github/workflows/kospi.yml`)가 평일 장 시간에 20분마다 `scripts/update_kospi.py`를 실행해
`kospi.json`을 갱신하고, 앱은 이 파일을 읽어 표시합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `weather.html` | 날씨 앱 본체 (HTML, CSS, JavaScript가 한 파일에 포함) |
| `index.html` | 사이트 기본 주소로 들어오면 `weather.html`로 이동시키는 페이지 |
| `kospi.json` | 코스피 전일·현재 지수 데이터 (자동 갱신) |
| `scripts/update_kospi.py` | 코스피 데이터를 받아 `kospi.json`을 만드는 스크립트 |
| `.github/workflows/kospi.yml` | 위 스크립트를 주기적으로 실행하는 GitHub Actions 설정 |

## 배포

GitHub Pages로 `main` 브랜치의 루트 폴더를 게시합니다.
`main`에 push하면 1~2분 안에 사이트에 자동 반영됩니다.
